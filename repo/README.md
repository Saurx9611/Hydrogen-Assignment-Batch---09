# Fixed-Bed Downdraft Gasifier Simulation — Batch 09

Gasification & Reforming Processes assignment (Fixed-Bed Gasifier). Simulation and validation of the 80 kWth NERD downdraft wood gasifier studied in:

> Jayah, T.H., Aye, L., Fuller, R.J., Stewart, D.F. (2003). *Computer simulation of a downdraft wood gasifier for tea drying.* Biomass and Bioenergy 25(5), 459–469. doi:10.1016/S0961-9534(03)00037-0

- Report: `report/Batch 09.pdf` (identical to `report/final_report.pdf`).
- Slides: `presentation/Batch_09_presentation.pptx`.

## Model

1. **Throat sub-model** (`src/flaming_pyrolysis.py`):
   - Air O₂ is consumed by the volatiles, with water-gas-shift equilibrium.
   - CH₄ is imposed at 1.2 %, as in Jayah's model.
   - Throat temperature = Jayah's 1604 K plus the change predicted by an enthalpy balance as AFR, moisture and air temperature vary.
2. **1D reduction zone** (`src/reactor_1d.py`, `src/reactions.py`):
   - Species, char, separate gas/char temperatures, shrinking particles, wall loss.
   - Reactions: Boudouard, water-gas, methanation, water-gas shift.
   - Solver: SciPy Radau.
3. **2D axisymmetric** (`src/reactor_2d.py`):
   - 12 annular finite-volume cells follow the cone, each running the 1D physics.
   - Radial dispersion of heat (including bed radiation) and species; wall loss at the outer cell.
   - Method of lines, Radau.
   - Reduces to the 1D model under strong mixing (tested). Not CFD.
4. **Calibration** (`src/calibration.py`) — three parameters, none fitted to validation data:
   - Wall U = 114.4 W/m²K, which gives Jayah's measured 12.8 % heat loss.
   - Char-reactivity factors η_B = 0.474 and η_WG = 0.142, fitted to Table 5.

Assumptions and their effects are listed in the report (Limitations). The two most influential are the throat-temperature anchoring and the water-gas-shift rate units.

## Reproduce

```bash
pip install -r requirements.txt
python run_simulation.py               # ~30 s: all figures (outputs/figures) and tables (outputs/tables)
python -m pytest tests                 # 20 tests
python -m src.calibration              # re-derive the three calibrated parameters
python scripts/make_report_tables.py   # regenerate report/generated/*.tex from the outputs
cd report && pdflatex final_report.tex && pdflatex final_report.tex
node scripts/generate_presentation.js  # needs Node + pptxgenjs (npm install pptxgenjs)
```
